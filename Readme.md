# Testimonial Cards

A responsive testimonial cards section built with HTML and CSS, created as part of a [roadmap.sh](https://roadmap.sh) frontend project to practice layout and positioning.

## What it does

Displays four client testimonial cards in a clean grid layout. Each card includes a quote, avatar, name, and role.

## Built with

- HTML5
- CSS3 (Grid, Flexbox)

## Features

- Responsive grid (2 columns on desktop, 1 column on mobile)
- Hover animation on cards
- Custom color theme with gradient accents

## Run it locally

1. Clone or download this repo
2. Open `testimonials.html` in your browser
